# 02 — jev-behavior-study（Jev 行为研究：输入表征杠杆）

- 研究日期：2026-09-20
- 仓库：https://github.com/RINNECODER/jev-behavior-study，commit `e4a1d7e`（2026-09-17）

## 概述

对 Jev（`jev-1.13.0`）的大规模行为研究，含贪吃蛇（snake_demo）、城市 demo、日常推理、洗车/平地/斜视等多个基准报告，全部带 PROTOCOL.md（预注册式协议：候选配置先冻结再上 held-out 种子 9101–9116，事后不修改提示词、不换种子、不重试）与 QA.md。

## 研究方法

- **无辅助（unassisted）贪吃蛇**：12×12 棋盘、8 食目标、200 步上限；Jev 的最终选择原样执行，求解器只在游戏结束后用于打分，不进入任何模型请求（无路线答案、无安全标签、无动作掩码）。
- 开发集 80 状态上测 8 种输入变体（原始/显式优先级/散文描述/ASCII 网格/头相对坐标/四步历史/绝对方向/双调用自审），预声明选择规则冻结决赛配置后再跑 16 局 held-out。
- 调用量：主研究 4,515 次成功调用；开发+holdout 阶段另有 720 请求；全仓库基准汇总 `valid_calls=6,394`（另有 city/carwash/平地等报告），与文章"超过 1.1 万次调用"量级相符（合计口径）。

## 关键发现（文章声称 vs 仓库实际证据）

| 文章声称 | 仓库证据 | 判定 |
|---|---|---|
| 超过 1.1 万次调用 | 单 snake 主研究 4,515 次、汇总 6,394 valid calls；各 demo 报告合计上万量级 | ✅ 大体可证实（取决于合计口径） |
| 输入改成清晰状态陈述 1/16 → 14/16 | unassisted REPORT：Original 1/16 vs Prose description **14/16**（Wilson 95%: 64.0–96.5%），冻结配置后 held-out，含配对比较 | ✅ 可证实，且方法学严谨 |
| 路径事实写进输入达 16/16 | 仓库明确区分：16/16 属于**早期 assisted 研究**（Jev 从代码算出的精确路线长度中选择）；unassisted 研究特意不提供任何路线信息 | ⚠️ 数字存在但语境不同：那是"求解器喂答案"的上限实验，非同等条件对比 |
| 输入表征是决定性杠杆 | 80 状态开发集：Prose 70/80 最短路 vs Original 55/80；head-relative 坐标单步 78/80 却在完整对局中撞车被预声明规则淘汰——表征好坏要看任务视野 | ✅ 定性可证实 |

补充发现：绝对方向 12/16、散文描述平均吃食 7.19 vs 3.06；API 中断按删失处理并如实披露；在贪吃蛇上确定性基线显著优于两个 Jev 配置。

## 评估结论

这是 9 个仓库中方法学最接近学术论文的一个（预注册、held-out、配对检验、删失处理）。它给文章最核心的论点——**"决定成败的是工程端的状态表达，而非模型间几个百分点"**——提供了最强的一手证据（1/16→14/16 = 87.5pp 的表征收益）。需修正的是：16/16 的满分来自喂入精确路线的 assisted 设置，不能作为"纯输入改写可达满分"的证据。
